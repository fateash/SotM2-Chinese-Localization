# 次元守护者 2｜简体中文汉化

为《Sentinels of the Multiverse 2》Steam 版制作的非官方简体中文汉化，由个人维护。项目以超级英雄漫画的中文表达为基础，统一角色与世界观译名，兼顾卡牌规则的准确性和风味文字的角色语气。

汉化面向 Windows 版游戏，内容涵盖界面、卡牌名称、规则正文与风味文字，并持续完善。不同版本的实际支持范围和适用游戏版本，以发布说明为准。

## 下载与使用

请在 [Releases 发布页](https://github.com/fateash/SotM2-Chinese-Localization/releases) 查看可用的汉化安装包。目前该页尚未提供公开安装包，发布后会在此更新下载与安装说明。

下载时请选择发布说明中标明的安装包；GitHub 的 **Code → Download ZIP** 是源码下载，不能直接作为汉化补丁安装。

安装包发布后，请按以下顺序操作：

1. 确认游戏版本符合该安装包的适用范围，并关闭游戏。
2. 在 Steam 库中右键点击游戏，选择“管理 → 浏览本地文件”，找到游戏目录。
3. 将安装包完整解压到独立文件夹，按包内说明运行安装程序，并指定游戏目录。
4. 安装完成后，通过 Steam 正常启动游戏。

## 更新与卸载

更新前请关闭游戏，并阅读新版本的发布说明。完整版和更新包的适用条件可能不同，请按说明选择。

如需恢复安装前状态或卸载汉化，请使用对应安装包提供的恢复或卸载方法。保留安装时产生的备份，直至确认更新后游戏运行正常。

游戏更新后若汉化无法使用，请先查看发布页是否已有适配版本。

## 问题反馈

遇到漏译、错译、排版或安装问题，可在 [Issues](https://github.com/fateash/SotM2-Chinese-Localization/issues) 提交反馈。请尽量附上：

- 游戏版本与汉化版本；
- 出现问题的界面、角色或卡牌名称；
- 能够复现问题的操作步骤与截图。

翻译文本在 [ParaTranz 项目](https://paratranz.cn/projects/21585) 中维护。规则含义与角色名称的修订会统一核对，避免同一内容在不同位置出现冲突。

本项目为爱好者制作的非官方汉化，与游戏开发商、发行商无隶属关系。原作角色、美术及相关内容的权利归各自权利人所有。
