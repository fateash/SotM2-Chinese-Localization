# 次元守护者 2｜简体中文汉化 0.1.45-rc.1

适用于 Windows x64 Steam 游戏 Build 26880829。此包为发布候选版本，安装脚本修订2。

包含当前已审定的文本、字体、六款基础反派角色字标及六款小牌背；英雄徽记暂未制作，Collection 等未开放内容不计入当前支持范围。汉化不改变卡牌规则、生命值或存档格式。

## 安装或更新

1. 完全退出游戏。在 Steam 游戏库中右键游戏，选择“管理 → 浏览本地文件”，复制游戏目录。
2. 将本包完整解压到游戏目录以外的独立文件夹，双击 `01-Install-or-Update.cmd`，粘贴游戏目录并回车。
3. 看到安装成功后，通过 Steam 正常启动。不要直接覆盖复制 payload 文件夹。

本包自带固定版本的加载器、运行库及本游戏版本所需互操作程序集，无须预装 BepInEx，也不依赖在线下载。未包含游戏主程序、GameAssembly.dll 或游戏元数据文件。游戏版本或现有共享加载器不匹配时，安装会在改动前停止。

更新会将旧汉化文件和重复汉化 DLL 移出插件目录，并保存在游戏目录下 `SotM2ChinesePlayerBackups`。只处理本项目文件；保留其他插件与存档。复制失败时自动恢复本次已移动文件。请保留备份，直至确认运行正常。

## 卸载与回退

关闭游戏后，运行 `02-Uninstall.cmd` 卸载汉化；运行 `03-Rollback.cmd` 恢复上一次安装前的本项目文件。两者都要求输入游戏目录。

卸载仅移除本项目安装且内容未被改动的文件，保留共享加载器、存档、其他插件以及备份。回退到旧内部测试版会恢复该旧版原有行为。卸载后不能再通过本包的回退入口恢复；需要时重新安装。

回退时，加载器启动后重新生成的扫描缓存会单独归档，再恢复安装前的缓存；不会因此覆盖其他新文件。

若安装后的文件被手动编辑，卸载／回退会停止，先自行保存修改并恢复该安装包原文件。不要直接删除整个 BepInEx 文件夹。
