# 六个基础反派小牌背

原小牌背将英文名称与漫画面板合并在一张图内，大牌背则使用独立字标。此目录保留以原小牌背和已审定中文字标为参考生成的中文小牌背图稿。图稿已检查名称与总体构图；用户已确认0.1.44-rc.1测试均通过（coverage/acceptance-closeout-0.1.44.json），不声称生成结果逐像素保持原画。

原始图集尺寸：黎明公民512×512，其余五款600×600。构建脚本`tools/build_villain_deckbacks.py`将整幅正方形图稿等比采样为原尺寸，不裁切、不添加透明边距；SOTMBCK1头部、6条严格名称和尺寸记录、RGBA32从底到顶排列，GZip压缩。

运行替换同时要求LoadCardImage传入的准确资源名、CardView.MainImage绑定、IsDeckBack、非IsFullCard以及原图rect尺寸；相同资源名的大图、其他控件、角色正面、变体与英雄不在映射内。缺失或损坏数据保留原图。小牌背数据与字标数据分别解码，失败互不覆盖。
