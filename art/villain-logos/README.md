# 基础反派中文字标

六款图稿由项目维护者在2026-11-28初审通过。BaronBlade.png为最终双刃稿：锋／男／爵横画连成略延长刀锋，刀字撇笔另成刃口。其余五款为首轮审定稿。原始RGBA图稿保持完整，不以运行适配覆盖原稿。

安装构建：先安装requirements-art.txt中的依赖，运行`python3 tools/build_villain_logos.py`，再向完整测试包构建传入`--logos build/villain-logos.bytes`。数据以GZip压缩，头部SOTMLOG1，六条记录，每条包含小端Int32名称字节数、ASCII精确资源名、宽、高、RGBA字节数以及Unity从底到顶排列的RGBA32像素。运行时校验数量、准确名称、原始画框尺寸及完整长度。

加工仅裁定透明外边距、等比缩放到原字标尺寸并留下4像素安全区、居中、转换像素方向。不同长宽比通过透明留白适配；不拉伸汉字、不改变构图、不绘制新笔画。运行时保留原Image画框、位置、颜色、材质及交互属性。

美术初审与实机显示验收分开。0.1.43-rc.1首次接入，实际字号、遮挡、翻面、切换和读档仍待本轮确认；覆盖契约为合成映射测试。
