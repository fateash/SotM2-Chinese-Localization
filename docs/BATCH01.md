3. 将本批 `Legacy.json` 和 `BaronBlade.json` **新增**为根目录两个独立文件，保留文件名及所有 key/original，不覆盖旧 `cards-body.json`。预期条数分别为 27、25。旧文件暂留作历史参考，迁移确认前勿删除；新流程仅拉取配置的三个活动文件。

在 ParaTranz 先选择卡组文件，再以卡牌 ID 或上下文筛选；同一张牌的正反面在同一个文件。未来变体也归入同一牌组，但须先核对运行 ID。卡名、风味与出处亦按牌组归档，待对应运行字段适配后加入，不能直接用正文接口套用。

当前文件名采用稳定程序 ID，避免角色译名定稿后反复重命名。花括号内的 `{Legacy}`、`{BaronBlade}`、`{Start}`、`{Power}`、`{H - 2}` 及翻面图标 `{Flip}` 保持原样。变量 `X` 也保留。不能为了中文显示直接改写占位符。
