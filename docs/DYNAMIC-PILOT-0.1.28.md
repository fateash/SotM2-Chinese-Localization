# 角色与卡组名称测试版 0.1.28-rc.1

适用于游戏构建26880829，以及已安装并正常运行的0.1.6至0.1.20测试版汉化。

本版补齐“打出物品牌”效果按钮、自毁程序下方有0张牌的结束原因，以及瓦格纳火星基地爆炸的结算标题。同时补齐反派弃牌堆至少15张牌、场上至少10个反派目标的结束原因；“胜利何价！”大小图标题统一。另补齐弃置全部手牌的提示，并为“突破极限”大图规则加入100%行距，保留字号、图标和全文，效果待实机确认。保留此前名称、提示和排版修正。Collection保留译文，待游戏开放后测试。

关闭游戏，解压后运行`01-Install-Dynamic-Pilot.cmd`，按提示指定游戏目录。安装会备份原插件和显示配置；现有正文译文、字体及用户设置保持不变。本包不包含新的全量正文词典。

请优先复查机偶回收的数量上限，以及奥术终止式的抽取、放回原处、弃置、埋藏四个选牌步骤，再检查英雄、反派及环境选择列表，开局后的回合名称，环境大卡／牌背标题，以及胜利或失败后的角色名称。切换角色、放大缩小和读档后再次检查。确认名称无错配、裁切或重复，并观察生命值和抽牌计数仍正常变化。

退出游戏后运行`02-Collect-Evidence.cmd`，将生成的记录与看到的问题一起反馈。需要撤销时，关闭游戏，运行`03-Restore-Previous.cmd`恢复安装前状态。

这是待实机验收的测试版。若安装器提示版本或文件不符，请保留提示；不要手动覆盖未知版本的文件。

火星基地缩略图标题已确认属于文字控件，本版仅增加受保护标题的只读输入状态记录，尚未确认修复。复查时请保留该画面对应日志。
