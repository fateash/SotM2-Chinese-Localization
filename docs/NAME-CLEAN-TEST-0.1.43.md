# 六个基础反派字标测试版 0.1.43-rc.1

适用于游戏构建26880829及已安装本项目兼容BepInEx基础运行环境的游戏目录。

本版在0.1.42已验收的文本、字体与显示修复基础上，新增刀锋男爵（双刃审定稿）、阿卡什怖妲、黎明公民、大军阀沃斯、全能智创、鸦母的中文图片字标。仅替换六个准确资源名对应的CardView.LogoImage；沿用原字标画框，等比缩放和透明留白，不修改立绘、卡牌正文、生命值、按钮、命中区域或游戏规则。其他变体字标保持原样。

关闭游戏，解压后运行`01-Clean-And-Install.cmd`，按提示指定游戏目录。完整替换本项目受管文件，旧版本隔离到游戏目录SotM2ChineseArchives，复制失败回退。游戏文件、存档、其他插件和共享基础运行库不改动。随后运行`02-Verify-Clean-State.cmd`核验插件、字体、词典和字标数据。

完全重启游戏后，依次查看六个基础反派角色大卡的正面与翻面（有原字标的位置），检查字形、比例、透明边缘与是否遮挡立绘、正文或生命值。特别检查刀锋男爵两个刃尖、阿卡什怖妲和全能智创的长标题，以及黎明公民、沃斯两行字标。请再快速切换反派、放大缩小、撤销、回主菜单和读档，检查是否闪回英文或串到其他角色；英雄、变体与环境图片应保持原样。界面若没有原字标，本版不会额外添加。

六款美术已通过初审，游戏内接入仍待本轮实机验收。日志会记录VILLAIN_LOGO_HOOK_INSTALLED、VILLAIN_LOGOS_READY与各资源VILLAIN_LOGO_APPLIED。资源异常时保留原字标；没有新增UI或遮盖层。

退出游戏后运行`03-Collect-Evidence.cmd`反馈记录与画面；需要撤销时关闭游戏并运行`04-Restore-Previous.cmd`。恢复不覆盖后续用户修改；不要使用旧版本脚本操作新安装。

本包为内部测试包，保留采集入口，不作为公开Release。此次新增字标独立验收，不重开已通过的38项文字验收及已放行历史采集记录。
