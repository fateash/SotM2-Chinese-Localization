# Batch01 Fix01：失能背面匹配与长句排版候选

用户于 2026-11-26 19:28 反馈本批整体画面测试通过，Legacy 失能背面三条能力未译，Baron Blade 正面“改为”和“游戏结束”出现不理想的折行。此记录只覆盖用户报告范围，不替代完整游戏验收。

## 已定位原因

运行日志中 LegacyCharacter 的 CARD_TEXT_UNMATCHED 并非纯正文，而是三行如下格式的组合（行间 CRLF）：

```text
<size=70%><sprite name="BulletPoint"></size><indent=1em>原始正文</indent>
```

运行 0.1.4 已支持按卡牌 ID 与完整行匹配，但现有纯正文不等于装饰后的完整行。原三条译文已存在，不能以重复创建协作词条解决。

## 修正

注册表仅为这三条已确认正文增加 `incapacitated-bullet-v1` 显示变体标记。构建时由同一译文生成纯正文和带格式匹配项，完整保留字号、项目符号、缩进及原文占位符。其他卡牌不会自动扩展；新增格式须单独核对。规则引擎、文本渲染、生命值与字体 DLL 均不改动，仍用 0.1.4。

ParaTranz 仍为 89 个稳定键，正文仍为 52 条，游戏词典额外生成 3 个显示匹配项，共 92 个运行条目。这三项不导出为独立翻译，未来修改或取消审核状态会与原词条一起更新/移除。拒绝未知变体、界面误用及生成的重复运行定位。

Baron Blade 两句候选缩写：

- `card.BaronBladeCharacter.body.003`：`{BaronBlade}被摧毁时改为{Flip}`
- `card.BaronBladeCharacter.body.004`：`若反派弃牌堆有15张或更多牌，{BaronBlade}的地月冲击光束启动，将月球拉向地球。<b>游戏结束。</b>`

保留替代摧毁的含义、15 张阈值、专名、翻面占位符与粗体标签，不硬编码换行。文本缩短是排版候选，实际换行仍取决于游戏布局，须实机复测。
