# 0.1.9-rc.1：确认按钮与效果选择

适用 Steam Build 26880829。直接在已安装的 0.1.8-rc.1 上更新；无需操作 ParaTranz。

## 本轮新增

- 弃牌确认：弃置 N 张牌；通用选择确认：选择 N 张牌。N 随当前选择变化，不缓存译句。
- 英雄选择按钮：打出一张牌、使用异能、放置一张牌；已观察的牌堆选择按钮：展示。匹配活动英雄区域及三英雄布局的已观察层级，不全局替换同名文字。
- 卡牌内效果按钮：The Staff of Ra 的“伤害翻倍”；Synaptic Interrupt / Silver Shadow 的抽牌、出牌；Keen Vision 的抽牌、使用异能。必须同时匹配卡牌 ID、完整原文以及选择效果按钮层级。
- 提示：带／不带来源卡名的出牌和异能提示；选择英雄、能力、召唤、置于牌堆顶、弃牌、展示；减伤目标选择；伤害顺序与反应提示。
- 寒冷／能量伤害类型。没有明确伤害量的原文继续省略数值，不凭卡牌规则补填。

Cold 按冻结术语表译为“寒冷”，Energy 为“能量”，Discard 为“弃置”，ability 为“能力”，Power 为“异能”。角色与卡名仍保留英文；Perform 等未审定专用标签本轮不新增译名。

`Select N cards` 在本次日志中用于减伤目标选择。游戏仍写 cards，因此本轮保持“选择 N 张牌”，不会改成弃牌，亦不根据上下文猜测成生命恢复量。

## 阶段次数标签

截图证明 `DRAW PHASE (2 LEFT)` 存在，但先前日志没有采集 Phase Label。本版已增加安全只读采集；此标签仍可能保持英文。回收完整字符串和数值变化后，再适配为带剩余次数的中文标签。本版不会为其绕过 TMP 数值缓冲保护，也不全局替换 left。

## 安装与测试

1. 关闭游戏，运行 `01-Install-Dynamic-Pilot.cmd`。支持已知的 0.1.6、0.1.7 和 0.1.8 文件组合；现有正文词典、字体和配置保留。
2. 在弃牌或通用选牌场景，增减所选牌，观察“弃置／选择 N 张牌”的数字、按钮状态和中文排版。
3. 触发英雄打牌／使用异能，以及上一轮出现的卡牌内效果按钮。观察是否正确翻译，同时确认旁边的 +1／+2 等状态数字不受影响。
4. 尽量重用带额外抽牌次数的场景，记录阶段标签从剩余 2 次到 1 次的变化；英文属于本轮预期。无需为每一种提示反复刷局。
5. 检查生命值变化，再读档或回菜单一次。退出游戏后运行 `02-Collect-Evidence.cmd`，提交 ZIP 和代表性截图。

`03-Restore-Previous.cmd` 恢复本包安装前的 DLL 和独立测试配置。若是从 0.1.8 升级，就回到 0.1.8。需要继续回退时，按安装相反顺序使用旧包恢复脚本。

## 验收边界

0.1.8 的生命值变化、读档／回菜单已获用户明确确认。两份日志证据为 SotM2-Dynamic-Evidence-20261127-085856-183706.zip 与 SotM2-Dynamic-Evidence-20261127-094253-401964.zip；安装哈希匹配，未发现 SURFACE_PROBE_STOPPED / UI_RENDER_FALLBACK / UPDATE_ERROR / CARD_FALLBACK / FONT_INIT_FALLBACK。

0.1.9 仍待 Windows 实机验证。新模板仅用于独立试验配置，不覆盖 ParaTranz；库存与 524 条暂存项不作生产放行。英雄变体、未开放重大事件和图鉴仍延后。

沿用原有预渲染入口、TMP 数值／脏字符串保护和正文有效替换检查。不调用 TMP.text getter，不改变规则模型、伤害量、生命值、选择结果或按钮可用状态。状态标签、异能正文和未登记的卡牌内按钮可被安全采集，但不进入新增翻译规则。
