# 角色与卡组名称测试版 0.1.33-rc.1

适用于游戏构建26880829，以及已安装并正常运行的0.1.6至0.1.20测试版汉化。

本版接入晶质小妖／晶质巨兽加入英雄手牌的提示和“放在此处”按钮、黄金之心的指定英雄抽N张牌、塑石工匠减伤、塔玛元帅选择伤害来源、科研资助选择数字，并修正宇宙冠饰按钮中Construct残留为“构造牌”。接入宇宙武器赋予其他英雄的异能正文。补齐无卡名来源头的目标伤害提示。沿用已审定卡名和术语，保留此前修复。

关闭游戏，解压后运行`01-Install-Dynamic-Pilot.cmd`，按提示指定游戏目录。安装会备份原插件和显示配置；现有正文译文、字体及用户设置保持不变。本包不包含新的全量正文词典。

请完整退出并重启游戏。重点检查当前英雄及非当前英雄手牌区的“放在此处”按钮，确认环境牌加入所选英雄手牌；检查抽牌数量、减伤目标和伤害来源提示；检查“宇宙冠饰”的“打出构造牌／发现构造牌”按钮与点击行为。另复查科研资助的选择数字提示，以及宇宙武器赋予快子等英雄的异能正文、点击和伤害结算。复查“点击至多2个目标，对其各造成2点近战伤害”等无卡名前缀提示。确认文字不裁切，数量、生命值和游戏动作正常。按场景使用短会话并及时采集；日志命中不等于画面或操作验收。

退出游戏后运行`02-Collect-Evidence.cmd`，将生成的记录与看到的问题一起反馈。需要撤销时，关闭游戏，运行`03-Restore-Previous.cmd`恢复安装前状态。

这是待实机验收的测试版。若安装器提示版本或文件不符，请保留提示；不要手动覆盖未知版本的文件。

火星基地缩略图标题已确认属于文字控件，本版仅增加受保护标题的只读输入状态记录，尚未确认修复。复查时请保留该画面对应日志。

本包仅供内部实机检测，包含采集与维护入口，不作为公开Release安装包。
