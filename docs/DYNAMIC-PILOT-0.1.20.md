# 角色与卡组名称测试版 0.1.20-rc.1

适用于游戏构建26880829，以及已安装并正常运行的0.1.6至0.1.19测试版汉化。

本版修正已反馈的异能按钮、正文参数、准备与进阶标签、放弃游戏提示、提示来源名称及伤害状态条。保留当前24个英雄、反派及环境的名称显示：选择列表、回合栏、结算页面，以及大卡中使用文字控件的标题。图片内的英文徽标尚未修改。Collection保留译文，待游戏开放后测试。

关闭游戏，解压后运行`01-Install-Dynamic-Pilot.cmd`，按提示指定游戏目录。安装会备份原插件和显示配置；现有正文译文、字体及用户设置保持不变。本包不包含新的全量正文词典。

请优先复查之前反馈的位置、状态修正条与免疫提示，再检查英雄、反派及环境选择列表，开局后的回合名称，环境大卡／牌背标题，以及胜利或失败后的角色名称。切换角色、放大缩小和读档后再次检查。确认名称无错配、裁切或重复，并观察生命值和抽牌计数仍正常变化。

退出游戏后运行`02-Collect-Evidence.cmd`，将生成的记录与看到的问题一起反馈。需要撤销时，关闭游戏，运行`03-Restore-Previous.cmd`恢复安装前状态。

这是待实机验收的测试版。若安装器提示版本或文件不符，请保留提示；不要手动覆盖未知版本的文件。
