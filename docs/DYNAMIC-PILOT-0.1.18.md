1. 关闭游戏，运行`01-Install-Dynamic-Pilot.cmd`，可直接从0.1.17升级。
2. 正常游玩遇到先发动选牌提示时，核对来源、受伤目标、伤害数量与类型，以及选牌后的交互；无需重新跑遍已通过的生命值和读档用例。
