# 图片资源接入规格 v1

当前冻结基线：0.1.44-rc.1（07f51d2）。已有六款基础反派字标与六款小牌背随玩家包交付。英雄徽记制作暂停；不生成占位图，也不扩大运行白名单。

## 每项资源必须提供

沿用 art/villain-logos/manifest.json 与 art/villain-deckbacks/manifest.json 的清单模式：owner（内部身份）、name（审定中文名）、sprite（实际原资源名）、file（相对图稿路径）、width/height（原资源输出尺寸）、sourceSha256、artReview、liveStatus，以及通过后填写的 acceptanceRef。不同用途分别建清单，不能仅靠中文文件名匹配运行对象。

字标采用透明 RGBA PNG；按 alpha≥8 的可见区域裁定边界并保留2像素抗锯齿余量，等比缩放，输出四周至少4像素余量，居中。opticalScale 允许0.5–1.0；每项光学比例经画面验收后冻结。小牌背采用完整方形 PNG，输出尺寸匹配原图集，当前黎明公民512×512，其余五款600×600。不把这些反派尺寸当作未来英雄资源的通用尺寸。

原始图稿尺寸可以不同，输出必须使用实际原资源尺寸。禁止拉伸、猜测英雄 sprite 名称、自动裁掉角色轮廓，或为了接入资源修改规则、数值和控件身份。编译器保存原图SHA256，转换至RGBA、上下翻转后用既有确定性gzip编码。发布时只附运行资源数据，不附生成草稿与维护报告。

## 运行接入与验收

当前只支持已登记的反派 LogoImage 和小牌背 MainImage。新增英雄徽记时，先取得英雄原资源名、尺寸、绑定控件与显示时序证据，再扩展对应白名单和资源编译器；仅把图片放入目录不会自动生效。

接入检查覆盖：身份一致、错误控件不替换、资源缺失／损坏保留原图、同控件切换角色先还原、首次呈现与异步加载、缩略图／大图实际支持范围、读档及回主菜单。保留原RectTransform、材质、颜色和点击行为。离线映射通过与实机视觉通过分别记录；新增资源不继承其他角色的验收结论。

每批新增资源生成独立版本与哈希后再进入玩家包；未完成的英雄徽记不阻塞当前发布候选包的安装验收。
