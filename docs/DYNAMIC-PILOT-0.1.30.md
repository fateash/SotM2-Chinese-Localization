# 角色与卡组名称测试版 0.1.30-rc.1

适用于游戏构建26880829，以及已安装并正常运行的0.1.6至0.1.20测试版汉化。

本版将“突破极限”大图正文行距从100%放宽到110%，保留字号、阶段图标和完整规则。补齐“考古发掘”的弃牌堆埋藏数量提示，以及“埋藏N张牌”确认按钮；0、1和复数数量分别核验。补齐“浓雾翻涌”等卡面效果选择按钮中的“弃置N张牌”。保留此前名称、洗回提示、短标题及结算修正。Collection保留译文，待游戏开放后测试。

关闭游戏，解压后运行`01-Install-Dynamic-Pilot.cmd`，按提示指定游戏目录。安装会备份原插件和显示配置；现有正文译文、字体及用户设置保持不变。本包不包含新的全量正文词典。

请完整退出并重启游戏，优先检查“突破极限”悬浮大图和独立大图的阶段标题、行距及末行；再复现“考古发掘”，检查提示及选择0、1、2、3张牌时的埋藏确认数量，并确认点击后埋藏行为正常。再检查“浓雾翻涌”的“弃置1张牌”效果按钮及点击行为。完成后立即采集日志。字号、数字、图标和末行应完整可见。110%行距尚待本轮实机确认。

退出游戏后运行`02-Collect-Evidence.cmd`，将生成的记录与看到的问题一起反馈。需要撤销时，关闭游戏，运行`03-Restore-Previous.cmd`恢复安装前状态。

这是待实机验收的测试版。若安装器提示版本或文件不符，请保留提示；不要手动覆盖未知版本的文件。

火星基地缩略图标题已确认属于文字控件，本版仅增加受保护标题的只读输入状态记录，尚未确认修复。复查时请保留该画面对应日志。
