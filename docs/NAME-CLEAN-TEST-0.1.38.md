# 角色与卡组名称测试版 0.1.38-rc.1

适用于游戏构建26880829及已安装本项目兼容BepInEx基础运行环境的游戏目录。安装前会核对游戏和关键运行库。

本版针对新游戏危险度越过面板右边界，单独调整环境／反派评分框：向左扩宽为160，右上锚点、右侧内缩10、单行右对齐、字号16～28自适应。仅作用于完整中文评分，数值保持原样。环境牌背名称补接TMP.text字符串写入入口，并以牌背属性和标题绑定覆盖缩略图／大图；不读取TMP.text或数字缓冲。

关闭游戏，解压后运行`01-Clean-And-Install.cmd`，按提示指定游戏目录。本包会安装本轮已审定正文词典、名称配置、插件和字体，并将中文开关重置为开启。

清理会隔离本项目旧插件目录、重复插件DLL、旧配置、历史测试备份、旧安装记录及可再生的插件扫描缓存。它们统一保存在游戏目录的`SotM2ChineseArchives`中，不参与插件加载；复制失败会回退。游戏文件、存档、其他插件和共享基础运行库保持原样。此处“纯净”指本汉化项目的受管运行文件一致，不表示整个游戏无其他Mod。

运行`02-Verify-Clean-State.cmd`可核验文件哈希、中文配置和重复DLL。新包包含当前已审定的可接入文本，尚未接入的条目不会因此自动生效。

请完整退出并重启游戏。①新游戏切换环境，优先复验危险度6及其他评分，确认数字保持在面板内；同看反派难度。②环境牌库缩略图及点开放大的牌背，确认瓦格纳火星基地、熔岩域等名称完整汉化，反复切换不恢复英文，牌库数量正常。瓦格纳火星基地特殊失败结算、演奏／伴奏／制造／灭绝四标题中文字形回退已经由用户确认通过，不要求为本次修改重跑相同结算。

退出游戏后运行`03-Collect-Evidence.cmd`，将生成的记录与看到的问题一起反馈。需要撤销时，关闭游戏，运行`04-Restore-Previous.cmd`恢复清理前状态。隔离归档继续保留；请勿使用旧测试包的卸载或恢复脚本操作新版本。

这是待实机验收的测试版。若安装器提示版本或文件不符，请保留提示；不要手动覆盖未知版本的文件。

环境牌背名称上版仍为英文已登记为失败，未标记验收完成。本版补齐实际字符串属性写入入口，保留完整名称和组件身份限制；大图不再仅依赖小图的父节点名称。若仍有英文，请随画面附本版采集记录，用于区分未命中入口与刷新覆盖。

本包仅供内部实机检测，包含采集与维护入口，不作为公开Release安装包。
