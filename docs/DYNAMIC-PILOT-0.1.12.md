# 0.1.12-rc.1：补齐卡牌上的“在此打出”

适用 Steam Build 26880829，可从已知 0.1.6～0.1.11 文件组合升级。继承0.1.11全部动态提示和按钮适配。

## 本轮修复

0.1.11仅匹配角色牌本身的“Play Here”。用户截图与 `SotM2-Dynamic-Evidence-20261127-110718-a31287.zip` 确认：角色牌按钮已显示“在此打出”，但场上Cosmic Crest的按钮仍为英文；同一日志还记录了角色牌旁Vitality Conduit的同类遗漏。实际DLL和配置哈希与0.1.11发布包一致。

本版增加两类小卡牌显示位置：英雄出牌区内的卡牌，以及角色牌旁区域内的卡牌。完整按钮原文必须为“Play Here”，控件必须为“Next To Selection Button”，并要求显示路径中的卡牌ID与实际卡牌ID一致；角色牌旁区域还校验所属英雄与角色牌身份一致。

原有角色牌按钮继续沿用。无新增译名，无规则、生命值或抽牌计数修改；不调用TMP.text getter。日志中的7个实际按钮路径已加入回归，含5个角色牌路径与2个小卡牌路径。新增路径待Windows实机验收。

## 安装与复测

1. 关闭游戏，运行 `01-Install-Dynamic-Pilot.cmd`。保留已有词典、字体与通用配置。
2. 重现对Cosmic Crest或角色牌旁卡牌选择打出位置的场景，确认按钮显示“在此打出”且仍可正常点击。
3. 如遇遗漏，截图并运行 `02-Collect-Evidence.cmd`；采集可在游戏运行时执行。

`03-Restore-Previous.cmd`恢复安装前的DLL和独立配置；从0.1.11升级即恢复到0.1.11。

扩围顺序继续为：动态／提示／按钮 → 非卡组固定文本 → 按卡组逐个审核。219条候选中的拼接片段仍在核验，本次修复不代表第一阶段全量完成。抽牌次数不递减已确认为原生问题，不重复要求对照测试。
