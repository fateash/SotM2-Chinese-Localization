# 角色与卡组名称测试版 0.1.32-rc.1

适用于游戏构建26880829，以及已安装并正常运行的0.1.6至0.1.20测试版汉化。

本版补齐“无情进击”的双段伤害排序提示、异能阶段效果与点击／拖动异能的前后组合提示，并修复日志中新发现的“冷液喷射”无数值寒冷伤害提示。主动检查三段伤害排序、出牌阶段组合和标签／数值边界；合成组合不代表实机已触发。保留此前行距、埋藏、弃置、阶段按钮和特殊失败结算修正。

关闭游戏，解压后运行`01-Install-Dynamic-Pilot.cmd`，按提示指定游戏目录。安装会备份原插件和显示配置；现有正文译文、字体及用户设置保持不变。本包不包含新的全量正文词典。

请完整退出并重启游戏，复现“无情进击”的目标排序提示，检查1点火焰及1点能量两段伤害仍分别显示；复现异能阶段的两种提示句序，检查阶段图标、文字、点击及拖动行为；再检查“冷液喷射”的寒冷伤害提示及实际结算。确认文字不裁切，数值与生命变化正常。按场景分开短会话，完成后及时采集日志；日志命中不等于画面或点击已验收。

退出游戏后运行`02-Collect-Evidence.cmd`，将生成的记录与看到的问题一起反馈。需要撤销时，关闭游戏，运行`03-Restore-Previous.cmd`恢复安装前状态。

这是待实机验收的测试版。若安装器提示版本或文件不符，请保留提示；不要手动覆盖未知版本的文件。

火星基地缩略图标题已确认属于文字控件，本版仅增加受保护标题的只读输入状态记录，尚未确认修复。复查时请保留该画面对应日志。

本包仅供内部实机检测，包含采集与维护入口，不作为公开Release安装包。
