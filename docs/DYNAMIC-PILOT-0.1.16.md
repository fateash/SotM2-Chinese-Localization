# 0.1.16-rc.1：共用按钮入口与动态提示扩围

适用Steam Build 26880829，可从已知0.1.6～0.1.15组合升级，保留现有词典、字体和通用配置。

## 0.1.15日志核查

`SotM2-Dynamic-Evidence-20261127-133733-891d6d.zip`确认0.1.15版本、DLL及动态配置均与交付一致。344条采集未达到当前上限，未发现审计所检查的采集、字体或渲染警告。

上轮9个修复组合中，本日志捕获到Upgrade Mode的牌库／弃牌堆召唤提示并记录动态命中；其余8个组合未出现，继续待验收，不因日志版本正确而自动视为通过。两处Title Label的可见性也未得到新证据。

## 修复范围

- 已有译文的25个入口遗漏：不同英雄、当前／非当前布局、牌区中的Draw、Discard，以及Skip Draw。
- 牌库Replace按钮与“选择放回原处或弃置”的完整提示。已核对触发效果原文，replace在这里表示放回原处。
- Freedom Tower牌库／弃牌堆的已观察选择控件。
- 指定英雄牌库及抽牌数量、选择英雄抽牌／弃牌的提示。
- 从手牌选择牌置于另一张牌下方、弃置至多N张手牌、破坏指定N张场上牌。精确数量与“至多”分别处理。
- 选择目标发动阶段效果，保留目标范围与阶段图标；不与“选择一张牌”混同。
- 未给出伤害数值的能量等伤害类型提示，保留其不指定数值的含义。
- Discover Item及Discover Golem操作按钮。Item沿用“物品”，Golem专名待卡组审核，不阻塞通用动作翻译。

新增12个模板，共修复61个实际原文／位置组合，其中25个此前已有译文但入口未接入。

## 主动防漏

已知结构内增加12位英雄×3类布局×5类入口动作的180个主动检查组合，检查共享功能的跨角色接入，减少等待实机逐一触发。合成组合与真实观察分开记录，仍待画面和交互验收；四英雄布局不凭空推定。

动态文本发现不应仅依赖实机：正式流程先核对文本库存、拼接语义及显示入口，再进行离线检查和实机验收。本轮入口矩阵是已落实的一组主动检查，不能代表全库存覆盖。

## 安装与观察

1. 关闭游戏，运行`01-Install-Dynamic-Pilot.cmd`，可直接从0.1.15升级。
2. 遇到展示后选择放回／弃置时，检查当前与非当前英雄，以及Freedom Tower牌区的按钮。
3. 遇到抽牌数、弃牌上限、指定破坏数量及目标阶段效果时，观察文字范围、数字和图标。
4. 正常游玩后运行`02-Collect-Evidence.cmd`；若有漏译或异常，保留完整画面。无需为了重复已经通过的生命值／读档测试额外安排一轮专门操作。

`03-Restore-Previous.cmd`恢复升级前DLL和独立配置，从0.1.15升级即恢复0.1.15。
