# 反派字标与小牌背测试版 0.1.44-rc.1

适用于游戏构建26880829及已安装本项目兼容BepInEx基础运行环境的游戏目录。

本版修正六个基础反派字标的有效边距与显示比例；鸦母先恢复展翼乌鸦，再以完整徽记校准比例。另加入六个基础反派的小牌背中文图片。小牌背主图仅在准确资源名、控件绑定、牌背用途、小图模式和原始图集尺寸同时匹配时替换；大牌背继续使用已有中文字标。

关闭游戏，解压后运行`01-Clean-And-Install.cmd`，按提示指定游戏目录。旧版本隔离到游戏目录SotM2ChineseArchives，复制失败回退；随后运行`02-Verify-Clean-State.cmd`。本包包含插件、词典、两款字体、字标和小牌背数据，不需要叠加旧测试包。

完全重启游戏后重点检查：

- 六个反派角色大卡正反面的标题比例、边距和遮挡；鸦母的乌鸦与汉字作为整体观察。
- 六个反派的小牌背中文，尤其是全能智创；点击放大后大牌背仍正常。
- 切换、翻面、撤销、读档和重启后不串图、不闪回英文；其他牌背和数值显示正常。

本轮图片及显示比例仍待实机验收。小牌背图稿使用图像编辑生成，需同时检查原漫画构图与细节是否符合预期，离线检查不代替美术验收。资源异常时保留原图，不新增交互控件。

退出游戏后运行`03-Collect-Evidence.cmd`反馈记录与画面；需要撤销时关闭游戏并运行`04-Restore-Previous.cmd`。恢复不覆盖后续用户修改；不要用旧版本脚本操作新安装。

本包为内部测试包，保留采集入口，不作为公开Release。既有38项文字验收及已放行历史采集记录继续有效；本轮只增加图片显示的验证。
