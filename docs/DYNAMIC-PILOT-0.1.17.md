## 安装与观察

1. 关闭游戏，运行`01-Install-Dynamic-Pilot.cmd`，可直接从0.1.16升级。
2. 正常游玩中重点观察反派／环境牌库和弃牌堆上的展示、放回、弃置按钮。无需为了矩阵一次性跑遍12个对象。
3. 遇到本轮新增提示时观察对象、数量、范围和阶段图标；发现漏译或布局异常时保留完整画面。
4. 运行`02-Collect-Evidence.cmd`采集日志。`03-Restore-Previous.cmd`恢复升级前DLL和独立配置。
