# 0.1.8-rc.1 动态提示中文测试

Steam Build 26880829。测试版，实机尚待验证。无需更新 ParaTranz。

## 本轮范围

承接 0.1.7-probe.1 的实机截图和日志：出牌提示“示·”及 HUD 名称“组·”已命中；日志捕获攻击目标数量 0→1→2→3、火焰和近战伤害选择、抽弃牌选择等。原始证据包为 SotM2-Surface-Evidence-20261127-084215-2f9eaf.zip。

本包改用临时中文模板，正常重启后不再产生“示·／组·”。不替换现有 sample-texts.json，不提交测试译文至 ParaTranz。

| 入口 | 本轮处理 |
| --- | --- |
| 出牌、使用异能提示 | 完整句子中文 |
| 攻击确认按钮 | 对 N 个目标造成伤害；保留当前选择数量 |
| 攻击目标提示 | 保留来源名称、上限、伤害量及富文本；本轮支持已观察到的火焰／近战类型 |
| 选择卡牌效果提示 | 中文句式，卡名原样保留 |
| 抽牌／弃牌选择提示 | 中文句式；按钮仅启用已观测的 Tachyon 对应路径 |
| 跳过出牌／异能阶段 | 中文按钮 |
| 临时全屏卡牌的抽牌／展示／出牌说明 | 中文句式，来源名称原样保留 |
| 卡牌内部效果按钮（例如 Double Damage） | 补充只读采集，保持英文，未宣称入口验证通过 |

未知句式、其他伤害类型、其他位置的同名按钮回退原文；不会全局替换句子碎片或角色名。英雄变体、未开放的重大事件和图鉴不安排本轮测试。生产库存仍为 2,444 条，524 条暂存项保持不输出。

Discard 按冻结术语表使用“弃置”，本包不批量改写旧译文中的用词。卡名／角色名保持英文是预期。没有加入人工换行，最终排版留待全量翻译后评估。

## 确认按钮的共用处理

本地游戏方法元数据确认 ActivationView、DealDamageActivationView、SelectCardActivationView 都提供 `GetFinishButtonText(activation, selectedCount)`。本包将确认文本解析为动作、数字和单位，区分目标数量、牌数量、HP 数值；动作译法按已验证的动作／单位组合登记。

目前只有 Damage + target(s) 有实际 0→1→2→3 证据，因此启用中文。弃牌、恢复及增减益确认按钮纳入同一采集和解析机制，未核实的动作保持英文。测试中的 Discard/Heal/Regain/Buff 是解析隔离用例，不声称这些就是游戏实际按钮原文。

## 使用方法

1. 关闭游戏。解压并运行 `01-Install-Dynamic-Pilot.cmd`，指定游戏目录。可直接从上一轮 0.1.7-probe.1 升级，也支持恢复后的已验收 0.1.6-rc.1。
2. 尽量重用刚才的场景：Ra 的 Consuming Flame、The Staff of Ra，以及 Tachyon 的攻击和抽弃牌选择。
3. 增减攻击目标，观察按钮数字 0/1/2/3 是否及时更新；确认提示的伤害量、类型、来源名称正确，并关注取消重选后有无旧文本。
4. 有机会时额外触发弃牌、恢复或增减益的确认选择；无需凑齐全部场景。这些确认按钮暂时可能保持英文，日志会记录完整句式及当前数字。
5. 观察提示、确认按钮和抽弃牌按钮是否出现中文、是否溢出／遮挡。Double Damage 暂时仍是英文，请正常触发一次供日志采集。
6. 检查受伤／恢复的生命值，再读档或回菜单一次，确认既有功能没有回退。
7. 退出游戏后运行 `02-Collect-Evidence.cmd`，提交生成的 ZIP 与代表性截图。

本包备份放在游戏目录 `SotM2ChineseBackups/dynamic-pilot-0.1.8`，不进入插件扫描目录。`03-Restore-Previous.cmd` 恢复本包安装前的 DLL 和配置：若此前安装的是 0.1.7，恢复后会重新出现上一轮标记；再运行 0.1.7 包的恢复脚本可回到 0.1.6。请按安装的相反顺序恢复。

## 实现边界

仅使用既有预渲染入口，继续跳过格式化数值缓冲和脏字符串，不读取 TMP.text getter，不修改模型、生命值或伤害结算。参数每次从当前完整显示句子提取；不缓存匹配后的译句。完整路径限定、完整句式匹配、长度限制和正则超时保护共同限制作用范围。

采集新增 CardView 内按钮候选，仍排除输入框；卡牌正文和 HP 不纳入新增采集。异常会停止本次采集／测试转换，既有菜单和正文适配仍继续。日志中的命中不替代实机验收。
