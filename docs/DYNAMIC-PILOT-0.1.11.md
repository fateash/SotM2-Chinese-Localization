# 0.1.11-rc.1：动态提示与按钮扩围

适用 Steam Build 26880829，可直接从已知 0.1.6～0.1.10 文件组合升级。继承此前修复，现有正文词典、字体及通用配置保留。

## 本轮新增

- 伤害类型按冻结术语覆盖寒冷、能量、火焰、邪能、闪电、近战、投射、精神、光耀、音波、毒素。
- 区分“点击至多N个目标”“点击N个目标”“点击指定目标及另外N个目标”。保留原文中的指定对象和伤害数值。
- 扩展伤害顺序、伤害反应提示；未给出伤害量的提示继续省略数值。
- 区域打牌提示和英雄角色牌旁的“在此打出”；破坏一张牌、手牌最少判定、跳过出牌。
- 阶段效果提示保留原有阶段图标与富文本，校验图标名称和阶段文字一致。
- 通用效果按钮：23种完整标签及5种数量模板。恢复生命值的数字与目标数量使用独立规则，不混用。
- 24种完整选择提示按完整原文匹配，仅用于提示栏；不会在卡牌正文中替换相同片段。
- 已有动态译文中的 Deck 引用统一为冻结术语“牌库”，Trash 保持“弃牌堆”。

通用效果按钮限定于 `Select Effect Container/Select Effect Button(Clone)/Label` 层级；“在此打出”还要求英雄与角色牌ID一致。不会将HP状态、异能正文或卡名作为通用按钮处理。

所有219条现有动态候选已另建审阅译稿，但115条拼接片段及其他尚未核验的完整句参数仍需继续重建和定位，本包不表示全量动态本地化已经完成。详见源码中的推进清单；不回填ParaTranz，不批量启用524条库存暂存文本。

## 测试

1. 若此前为原生问题对照关闭了汉化，先将 `BepInEx/config/sotm2.zh.prototype.cfg` 中 `EnableChinese` 恢复为 `true`，关闭游戏后安装本包。
2. 继续现有局面，优先观察音波／毒素、固定数量／指定目标的提示，Captain Cosmic卡牌的“在此打出”，以及破坏与手牌最少选择。
3. 出现恢复生命值、抽牌、造成伤害等卡牌效果按钮时，检查中文与数字；这些场景按自然遇到的顺序验证，无需逐张刷牌。
4. 确认HP变化及一次读档／返回菜单仍正常。采集可在游戏运行时执行；遇到漏译时保留完整提示截图并运行 `02-Collect-Evidence.cmd`。

`03-Restore-Previous.cmd` 恢复安装前的DLL与独立配置；若从0.1.10升级，则恢复到0.1.10。

## 已确认原生问题

用户已通过关闭汉化的对照测试确认：抽牌阶段抽入第一张牌后仍显示“剩余2次”属于原游戏问题。本包保持原游戏提供的次数，不改规则计数。此项不再作为汉化阻塞项，也不要求重复测试。

本版新增文本与排版待Windows实机验收。沿用现有显示挂钩、TMP数值缓冲与脏字符串保护，不调用TMP.text getter，不改变伤害、生命值、抽牌或选择逻辑。
