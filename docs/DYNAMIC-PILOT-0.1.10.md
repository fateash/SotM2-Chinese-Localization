# 0.1.10-rc.1：阶段剩余次数

适用 Steam Build 26880829，可直接覆盖安装在 0.1.9-rc.1 上；继承 0.1.9 的动态按钮和提示适配。

## 本轮修复

- `PLAY PHASE (N left)` → `出牌阶段（剩余N次）`。
- `DRAW PHASE (N left)` → `抽牌阶段（剩余N次）`。
- 每次显示使用游戏当前数字，限定 HUD 的完整阶段标签路径；不缓存次数，不全局替换 left。

证据 `SotM2-Dynamic-Evidence-20261127-100444-b1520f.zip` 中 DLL、独立配置和词典哈希均匹配 0.1.9 及已接受的术语词典。捕获同一路径 `Canvas/HUD Panel/State Box/Phase Box/Phase Label` 的 `PLAY PHASE (3 left)` 与 `PLAY PHASE (2 left)`，输入类型均为 TextString。画面大写 LEFT 是显示效果，原始字符串为小写 left。

抽牌阶段已由此前截图证明存在，按相同结构覆盖；尚未取得其带次数的原始日志，因此抽牌中文仍须实机验证。异能及其他阶段的带次数形式不在本轮新增范围。

## 安装与验证

1. 关闭游戏，运行 `01-Install-Dynamic-Pilot.cmd`。支持已知 0.1.6～0.1.9 DLL／配置组合。
2. 重用额外出牌场景，观察“出牌阶段（剩余3次）”变为“出牌阶段（剩余2次）”；继续出牌时数字应跟随变化，恢复无后缀标签时仍应显示中文。
3. 若有额外抽牌场景，观察“抽牌阶段（剩余2次）”及后续变化，确认标签完整、无溢出。
4. 检查生命值刷新，完成一次读档或返回菜单。0.1.9 新增按钮仍可顺带验证，无需重新刷全套场景。
5. 在相关标签仍显示时运行 `02-Collect-Evidence.cmd`，再提交生成的 ZIP 与代表性截图。采集支持游戏运行中执行；采集前不要重启游戏，以免日志被覆盖。

`03-Restore-Previous.cmd` 恢复本包安装前的 DLL 和独立配置。从 0.1.9 升级即恢复到 0.1.9；继续回退须按安装相反顺序使用旧包恢复脚本。现有正文词典、字体、通用配置保留。
