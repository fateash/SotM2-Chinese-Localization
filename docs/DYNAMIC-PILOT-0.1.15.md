新增8个模板，修复本次日志中9个实际原文／位置组合：

- 大图关联牌区的“某张牌下方的牌”标题。

## 安装与观察

1. 关闭游戏，运行 `01-Install-Dynamic-Pilot.cmd`，可直接从0.1.14升级。
2. 查看Flak Cannon或Mounted AP Gun等牌下方的牌列表，检查标题。
3. 自然遇到Piston Punch、Still Life、Conductive Installation、Upgrade Mode等效果时，检查上述操作提示的中文与范围，确认点击行为正常。
4. 如关联牌列表画面出现字面文字`Title Label`，保留截图与当时打开的牌。日志已捕获两处该文字，但尚不能判断是否仅为初始化占位；本轮没有猜译它。
5. 运行 `02-Collect-Evidence.cmd`汇总日志；可在游戏运行时采集。

`03-Restore-Previous.cmd`恢复升级前DLL和独立配置；从0.1.14升级则恢复0.1.14。
